# 收工日誌 (Dev Log) - 2026-11-25 (捷徑腳本編碼修正)

## 📌 問題
- 在繁中 Windows 上執行 `scripts/create_shortcut.py` 會當掉：先出現 cp950 `UnicodeDecodeError`，接著 `AttributeError: 'NoneType' object has no attribute 'strip'`。

## 📌 原因
- 腳本以 PowerShell 取得桌面路徑，subprocess 預設用系統碼頁（cp950）解碼輸出；桌面路徑含非 cp950 字元或輸出為 UTF-8 時解碼失敗，stdout 變成 `None`，後續呼叫 `.strip()` 即當掉。

## 📌 修正
- `scripts/create_shortcut.py`：新增 `get_real_desktop()`；PowerShell 端設定 `[Console]::OutputEncoding` 為 UTF-8，subprocess 加上 `encoding="utf-8", errors="replace"`。
- 行為變更：讀不到桌面路徑時回傳空字串並改用後備路徑，不再中斷；建立捷徑失敗時印出 stderr。

## 📌 驗證
- `get_real_desktop()` 可取得存在的桌面路徑。
- `python -m pytest -q`：450 passed。

## 📌 已知問題
- 更換 `icon.ico` 後，Windows 圖示快取不會自動更新桌面捷徑；`ie4uinit.exe -show`、`-ClearIconCache` 都無效。
- 把捷徑 `IconLocation` 改寫成不同路徑字串（例如 `assets\..\assets\icon.ico,0`）才會重新讀取。
- 日後重跑 `create_shortcut.py` 會把路徑寫回原本的字串，可能又顯示舊的快取圖示。
