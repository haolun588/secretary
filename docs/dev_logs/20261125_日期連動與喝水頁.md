# 收工日誌 (Dev Log) - 2026-11-25 (日期連動與喝水頁)

## 目標
- 行程對話框的結束時間跟著開始時間連動，避免只在儲存時才被擋下。
- 喝水提醒由「設定頁區塊」改為獨立頁面。

## 做法
- `ui/calendar_dialog.py`：`DatePopupButton.dateChanged`（只在使用者選日期時發出）；`CalendarDialog` 以 `_duration_minutes`（定時）與 `_duration_days`（全天）兩個變數記錄長度，初始化／編輯載入後／切換全天時重算。改開始 -> 結束 = 開始 + 長度（以 UTC spec 的 QDateTime 做牆上時間運算，避免夏令時間偏移；全天時不動隱藏的結束時間 combo）；改結束 -> 合法則更新長度，否則標 `invalid` 並停用儲存鈕。程式更新結束欄位時用 `_syncing` 旗標避免遞迴。
- `ui/styles.py`：`DatePopupButton[invalid]`、`QDialog QComboBox[invalid]` 紅框（`DANGER`）；新增 `WaterPage`、`WaterCountdown` 樣式。`ui/theme.py` 新增 `FONT_DISPLAY = 48`。
- `ui/water_view.py`：新頁面，控制項（`chk_water_enabled`、`spin_interval`、`test_btn`）與 signal（`water_enabled_signal`、`test_toast_requested`）行為自設定頁原樣搬移；`set_countdown(seconds|None)`。
- `ui/nav_sidebar.py`／`ui/main_window.py`／`main.py`／`scripts/render_preview.py`：頁面常數與堆疊順序調整、移除 water_requested、main 改綁 `water_view` 並每秒餵倒數。
- `ui/settings_view.py`：移除喝水區塊、`scroll_to_water`、相關 signal。

## 測試
