# 2026-11-25 Logo 改版

## 目標
以新 logo（青綠漸層圓角方塊＋白色日曆＋時鐘）統一工作列、視窗標題列、系統匣、桌面捷徑與側邊欄，淘汰 ⚡ emoji 圖示與側欄勾勾方框。

## 變更
- 新增 `assets/logo.svg`（品牌原稿）。
- `scripts/icon_generator.py`：以 `QSvgRenderer` 渲染 logo.svg，輸出 `assets/icon.png`（256x256 透明）與 `assets/icon.ico`（16/24/32/48/64/128/256，每個尺寸各自從 SVG 渲染，手寫 ICO 檔頭＋PNG 內嵌）。
- `ui/icons.py`：新增 `logo_pixmap(size)`（原色、處理 devicePixelRatio、含快取與 `clear_caches`）。
- `ui/nav_sidebar.py`：`self.logo` 改用 `icons.logo_pixmap`；`#NavLogo` 為 `background: transparent`，無外框。
- `main.py`：`get_app_icon()` 後備改用 logo.svg；Windows 下於建立 QApplication 前呼叫 `SetCurrentProcessExplicitAppUserModelID("Secretary.DesktopAssistant")`（try/except）。
- 刪除 `assets/icons/logo.svg`；`tests/test_icons.py` REQUIRED 移除 logo；新增 `tests/test_logo.py`。
- `scripts/create_shortcut.py` 已使用 `assets/icon.ico`，未修改（建立 .lnk 時未設定 AppUserModelID）。

## 注意事項
- 既有桌面捷徑需重新執行 `scripts/create_shortcut.py` 才會換成新圖示。
- Windows 圖示快取可能需要重新整理，例如執行 `ie4uinit.exe -show`，必要時重啟檔案總管。
- 未實機驗證工作列／系統匣顯示。
