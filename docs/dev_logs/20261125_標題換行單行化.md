# 收工日誌 (Dev Log) - 2026-11-25 (標題換行單行化)

## 📌 問題
- 行程標題含換行（例如 "Introduction to Digital\nCommunication"）時，月曆格 chip 與右側面板標題列的文字上下被切、擠成一坨。

## 📌 原因
- chip 與標題列只預留一行高度，但 `QFontMetrics.elidedText` 不處理 `\n`，`drawText` 仍會畫出兩行並垂直置中，超出可視高度。

## 📌 修正
- `ui/styles.py`：新增 `single_line(text)`，以 `" ".join(str(text).split())` 把任何空白合併為單一空格；`fit_text` 先單行化再 elide（月曆 chip、週／日行程區塊、全天 chip 皆經 `fit_text`，一併修正）。
- `ui/side_panel.py`：`_ElidedText` 新增 `_display`（單行化文字）供 `paintEvent`／`sizeHint` 使用；`text()` 與 tooltip 保留原文。
- 其他 `drawText` 呼叫（週名、日期數字、「全天」、「+N」、時間文字）非行程標題，未更動。

## 📌 驗證
- 新增 `tests/test_styles.py`：`single_line`、`fit_text` 不含換行、`_ElidedText` 保留原文但顯示單行。
- 語法檢查與 `python -m pytest -q` 結果：`python -m pytest -q`：450 passed。
